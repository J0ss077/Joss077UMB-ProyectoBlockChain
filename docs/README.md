# Documentación

Índice de la documentación del proyecto. El vocabulario del dominio es el de `CONTEXT.md`, en la raíz del repositorio.

| Documento                                  | Contenido                                                                         |
| ------------------------------------------ | --------------------------------------------------------------------------------- |
| [arquitectura.md](arquitectura.md)         | Caso de aplicación, alcance, ciclo de vida, modelo de datos, módulos y límites.   |
| [base-de-datos.md](base-de-datos.md)       | Tablas, columnas, constraints, índices, seed y estructura congelada.              |
| [puesta-en-marcha.md](puesta-en-marcha.md) | Requisitos, configuración, comandos y problemas conocidos.                        |
| [referencias.md](referencias.md)           | Fuentes bibliográficas y artefactos del proyecto que viven fuera del repositorio. |
| [adr/](adr/README.md)                      | Decisiones de arquitectura, numeradas y con su contexto.                          |
| [agents/](agents/README.md)                | Configuración interna: tracker de issues, etiquetas y documentación de dominio.   |

El punto de entrada del repositorio es el `README.md` de la raíz. Las convenciones de trabajo del repositorio están en `AGENTS.md`.

Los documentos de entrega de cada fase se manejan por fuera del repositorio. Lo que tengan de permanente se incorpora acá.
