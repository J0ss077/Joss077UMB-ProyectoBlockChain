{# Macros de los datos que se muestran en las páginas de trabajo. `corto` recorta una clave, un identificador o un hash a su forma corta. `dato` la pinta en monoespaciada y deja el valor completo en `title` y en `data-copiar`, así que la pantalla muestra poco sin perder el dato. `copiar` es el botón accesible que copia ese mismo valor: sin el valor completo a un clic, la forma corta convertiría en pérdida lo que antes se podía copiar. `identidad` junta las dos con el nombre del dueño encima; no escribe el atributo de copia por su cuenta, para que `dato` y `copiar` sigan siendo las únicas que lo hacen. #} {% macro corto(valor) -%} {%- set texto = valor|string -%} {{ texto[:8] }}…{{ texto[-4:] }} {%- endmacro %} {% macro dato(valor) -%} {%- set texto = valor|string -%} {{ texto[:8] }}…{{ texto[-4:] }} {%- endmacro %} {# Un monto sin los ceros que sobran: 1000.00000000 se lee 1000 y 12.50000000 se lee 12.5. El valor exacto, con sus ocho decimales, queda en el `title`. #} {% macro cantidad(valor) -%} {%- set exacto = "%.8f"|format(valor) -%} {{ exacto.rstrip("0").rstrip(".") }} {%- endmacro %} {% macro copiar(valor, que="el valor completo") -%} {%- set texto = valor|string -%} {%- endmacro %} {# El nombre del dueño en negrita y, debajo, el código corto con su botón de copiar. `nombre` vacío pinta «Sin dueño»; `propio` pinta el chip «Tú»; `con_nombre=False` deja sólo el código (la cola de pendientes no puede listar nombres de aprobadas). `marca` agrega una etiqueta corta junto al nombre («esta» en el historial). #} {% macro identidad(valor, nombre=None, que="el identificador", propio=False, con_nombre=True, marca=None) -%} {%- if con_nombre or propio %} {%- if propio %}Tú {%- elif nombre %}{{ nombre }} {%- else %}Sin dueño{% endif %} {%- if marca %}{{ marca }}{% endif %}{% endif %} {{ dato(valor) }}{{ copiar(valor, que) }} {%- endmacro %}
