{# Píldora del estado de una transacción, con el texto en español. Sólo para las tablas cuyo marcado no fijan las pruebas: en las que sí, la celda queda `pending` y la píldora la dibuja el CSS. Con `simple` habla como el usuario común: «En espera» y «Completada» en vez de pool y confirmación. #} {% macro estado(valor, simple=False) -%} {%- set clave = valor|string -%} {%- if simple -%} {%- set textos = {"pending": "En espera", "confirmed": "Completada", "rejected": "Rechazada"} -%} {%- else -%} {%- set textos = {"pending": "En el pool", "confirmed": "Confirmada", "rejected": "Rechazada"} -%} {%- endif -%} {{ t(textos.get(clave, clave)) }} {%- endmacro %}
