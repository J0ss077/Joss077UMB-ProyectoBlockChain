# Definir la capa de presentación

Status: needs-info

## Contexto

`docs/arquitectura.md` deja la forma de la capa de presentación como decisión abierta. Hoy el backend solo se usa desde una sesión interactiva de Python.

## Qué falta

Decidir si la presentación será una interfaz de línea de comandos, una API local o una interfaz gráfica. La decisión no afecta al núcleo de dominio, que ya está separado.

## Done cuando

La forma elegida queda registrada en `docs/arquitectura.md` y, si resulta costosa de revertir, en un ADR.
